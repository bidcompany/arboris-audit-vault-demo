# Arboris Audit Vault

Open this folder as an Obsidian vault, then start from `00 Home/Start Here.md`.

The dataset is entirely synthetic and contains ten Food and Beverage audit reports and fifty findings.

## Report model revision

The ten source reports use the independent Audit Review V2 structure with four ratings: Satisfactory, Minor Gaps, Major Gaps and Unsatisfactory. Finding IDs and factual records are unchanged.
