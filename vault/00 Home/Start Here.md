# Start Here

This vault turns ten synthetic Food and Beverage audit reports into a navigable knowledge base. Start from [[Audit Dashboard]].

## Recommended reading order

1. Open [[Audit Dashboard]].
2. Select a report or priority finding.
3. Use backlinks and local graph to move between findings, sites and audit sections.
4. Install the recommended plugins using [[Installation Guide]].
5. Configure AI only after reading [[Security and Data Handling]].

## What is already included

- ten report notes (2026 audits and 2027 follow-ups);
- fifty atomic finding notes;
- site profiles and audit-section taxonomy;
- Dataview dashboards and action tracking;
- Word source files in `90 Attachments`;
- templates for new audits and findings;
- an AI prompt library designed for evidence-based analysis.

All records are synthetic. The architecture is suitable for real reports, but security and retention controls must be approved before importing confidential material.
